count

Counts rows or non-NULL values in an aggregate query.

Syntax

COUNT([DISTINCT] expr)
COUNT(*)

Parameters

expr: the value to count. DISTINCT counts unique values.

Return value

Returns the number of matching rows or values.

Examples

SELECT COUNT(*) AS row_count,
       COUNT(DISTINCT user_id) AS user_count
FROM events;

keyword

COUNT
