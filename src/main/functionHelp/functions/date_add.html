date_add

Adds a specified time interval to a date or datetime value. ADDDATE is an alias.

Syntax: DATE_ADD(date, INTERVAL value unit)

Parameters: date is the input date or datetime; value and unit define the interval to add.

Returns: The date or datetime after the interval is added.

SELECT DATE_ADD('2024-01-01', INTERVAL 1 MONTH);
