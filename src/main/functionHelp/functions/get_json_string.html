get_json_string

Extracts a string value from a JSON document using a JSON path.

Syntax

GET_JSON_STRING(json_doc, json_path)

Parameters

json_doc: a JSON string. json_path: the path of the value to extract.

Return value

Returns the extracted string, or NULL when the path does not resolve to a string.

Examples

SELECT GET_JSON_STRING('{"store_id":"s1"}', '$.store_id');

keyword

GET_JSON_STRING
