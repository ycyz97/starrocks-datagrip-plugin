xx_hash32

Returns the 32-bit XXH32 hash value of the input string.

Syntax

INT XX_HASH32(VARCHAR input, ...)

Examples

MySQL > select xx_hash32(null);
+-----------------+
| xx_hash32(NULL) |
+-----------------+
|            NULL |
+-----------------+
MySQL > select xx_hash32("hello");
+--------------------+
| xx_hash32('hello') |
+--------------------+
|          -83855367 |
+--------------------+
MySQL > select xx_hash32("hello", "world");
+-----------------------------+
| xx_hash32('hello', 'world') |
+-----------------------------+
|                  -920844969 |
+-----------------------------+
