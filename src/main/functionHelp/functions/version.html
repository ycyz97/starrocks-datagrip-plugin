version

Returns the current version of the MySQL database.

You can use current_version to query StarRocks version.

Syntax

VARCHAR version();

Parameters

None

Return value

Returns a value of the VARCHAR type.

Examples

mysql> select version();
+-----------+
| version() |
+-----------+
| 5.1.0     |
+-----------+
1 row in set (0.00 sec)
