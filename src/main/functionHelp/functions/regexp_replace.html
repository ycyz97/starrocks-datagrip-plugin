regexp_replace

Replaces substrings that match a regular expression.

Syntax

REGEXP_REPLACE(source, pattern, replacement)

Parameters

source: the input string. pattern: the regular expression. replacement: the replacement text.

Return value

Returns the input string with matching substrings replaced.

Examples

SELECT REGEXP_REPLACE('order-123', '[0-9]+', 'id');

keyword

REGEXP_REPLACE
