unnest

Expands an array into a table of rows and can be used as a table function in the FROM clause.

Syntax

UNNEST(array_expr)

Parameters

array_expr: an array expression to expand.

Return value

Returns a table containing one row for each array element.

Examples

SELECT item
FROM UNNEST(['a', 'b', 'c']) AS t(item);

keyword

UNNEST
