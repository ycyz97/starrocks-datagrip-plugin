ifnull

Returns a fallback value when the first expression is NULL.

Syntax

IFNULL(expr1, expr2)

Parameters

expr1: the value to test. expr2: the value returned when expr1 is NULL.

Return value

Returns expr1 when it is not NULL; otherwise returns expr2.

Examples

SELECT IFNULL(NULL, 'unknown');

keyword

IFNULL
