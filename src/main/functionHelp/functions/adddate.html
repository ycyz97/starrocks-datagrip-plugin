adddate

Adds an interval or a number of days to a date or datetime value. ADDDATE is a synonym of DATE_ADD.

Syntax: ADDDATE(date, INTERVAL value unit) or ADDDATE(date, days)

Parameters: date is the input date or datetime; value and unit define the interval; days is an integer day count.

Returns: The date or datetime after the interval is added.

SELECT ADDDATE('2024-01-01', INTERVAL 1 MONTH);
SELECT ADDDATE('2024-01-01', 7);
