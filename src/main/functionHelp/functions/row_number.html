row_number

Assigns a sequential number to each row within an analytic window.

Syntax

ROW_NUMBER() OVER ([PARTITION BY ...] ORDER BY ...)

Parameters

The function takes no arguments. The window clause controls partitioning and order.

Return value

Returns a 1-based integer row number for each row in its window.

Examples

SELECT user_id,
       ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY event_time) AS rn
FROM events;

keyword

ROW_NUMBER
