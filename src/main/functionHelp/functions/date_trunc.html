date_trunc

Truncates a date or datetime to the specified time unit.

Syntax

DATE_TRUNC(unit, datetime)

Parameters

unit: a supported unit such as day, month, or year. datetime: the value to truncate.

Return value

Returns a date or datetime aligned to the beginning of the selected unit.

Examples

SELECT DATE_TRUNC('month', '2026-10-29 14:30:00');

keyword

DATE_TRUNC
