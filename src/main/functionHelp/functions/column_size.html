column_size

Returns the decompressed size of a table column in bytes for storage analysis and optimization. Use the [_META_] hint to inspect segment file metadata.

Syntax

SELECT column_size(column_name) FROM table_name [_META_];

Parameters

  • column_name: the name of the column for which you want to get the decompressed size.

Return value

Returns the decompressed size of the column in bytes as a BIGINT value.

Usage notes

  • The function must be used with the [_META_] hint.
  • For complex data types, the function recursively calculates the size of all sub-columns.

Examples

SELECT column_size(name) AS name_decompressed_size
FROM products [_META_];

keyword

COLUMN_SIZE
